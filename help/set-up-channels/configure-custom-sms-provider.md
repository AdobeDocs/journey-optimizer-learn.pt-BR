# Configurar um provedor de SMS personalizado

Saiba como configurar um provedor de SMS que não seja Sinch, Twilio ou Infobip no Adobe Journey Optimizer, configurar credenciais de API e webhooks para mensagens de entrada, gerenciar palavras-chave de aceitação/recusa e iniciar campanhas de SMS personalizadas usando ferramentas nativas e conteúdos personalizados.

Consulte [Configurar um provedor de SMS personalizado](https://experienceleague.adobe.com/pt-br/docs/journey-optimizer/using/channels/sms/configure-sms/sms-configuration-custom) para obter mais informações.
